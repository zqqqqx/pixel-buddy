Pixel installieren

Für das Spotpear ESP32-S3 „muma“ Board mit 1,54″-Display. Funktioniert in Chrome oder Edge am Computer. Danach hält er sich über GitHub selbst aktuell.

  1. Board per USB-C anschließen.
  2. Auf „Installieren“ klicken und den Port wählen (meist „USB JTAG/serial debug unit“).
  3. Nach dem Neustart zeigt Pixel einen QR-Code: mit dem Handy scannen, WLAN wählen, OpenAI-API-Key eintragen – fertig.
Dieser Browser kann keine USB-Geräte flashen – bitte Chrome oder Edge nehmen.

Danach: Webinterface unter http://pixel.local. BOOT-Taste 5× schnell drücken öffnet ein Menü (Neustart, Ausschalten, Werkseinstellung).
